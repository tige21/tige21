Фронтендер из Питера. Основное - React и TypeScript, но чаще всего интереснее то, что рядом: Telegram, боты, LLM. В пет-проектах в основном с этим и вожусь.

Что можно глянуть:

**Spark Cards** - карточная игра для разговоров, вопросы к колодам придумывает языковая модель. iOS, Android и мини-приложение в Telegram. [лендинг](https://github.com/tige21/spark-landing)

**По зеркалам** - тренажёр парковки и манёвров в браузере. 3D нарисован руками на Canvas 2D, без движка. [demo](https://pozerkalam.space)

**marketbox** - магазин внутри Telegram, React 19, работает и без сети. [demo](https://marketandbox.ru/app/)

**Долой уныние** - [одностраничник](https://github.com/tige21/doloy-unynie-landing) с анимацией по скроллу.

Стек: React, TypeScript, React Native, немного Python/FastAPI, OpenAI/Claude, PostgreSQL.
