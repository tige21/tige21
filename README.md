Фронтендер из Питера, пять лет в проде. Основное — React и TypeScript, но чаще всего затягивает то, что рядом: Telegram, боты, LLM. В пет-проектах этим и занимаюсь.

Что можно посмотреть:

**Spark Cards** — карточная игра для разговоров, вопросы к колодам придумывает языковая модель. Есть под iOS, Android и как мини-приложение в Telegram. → [лендинг](https://github.com/tige21/spark-landing)

**По зеркалам** — тренажёр парковки и манёвров прямо в браузере. 3D там нарисован руками на Canvas 2D, без игрового движка. → [demo](https://pozerkalam.space)

**marketbox** — магазин, который живёт внутри Telegram. React 19, работает даже без сети. → [demo](https://marketandbox.ru/app/)

**Долой уныние** — [одностраничник](https://github.com/tige21/doloy-unynie-landing) с анимацией по скроллу.

Стек, если коротко: React, TypeScript, React Native, немного Python и FastAPI, OpenAI/Claude, PostgreSQL.
